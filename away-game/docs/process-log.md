## 2026-09-18: set up the project, revised the task model

- **Did:** Pulled my three HCI assignments (task modeling, bootlegging, personas) into one project around the traveling-athlete problem from bootlegging. Built v0.1 of the Routine Rings prototype.
- **Learned:** My class task models were user flows. The feedback pointed out that a task model is about the decision-making behind actions, not the action sequence. Redoing the wake-up routine around "what is he trying to figure out?" made most of the original boxes (shampoo, conditioner) disappear and brought my partner's side notes ("stares at the wall") to the center.
- **Changed because of it:** The project task model is organized around 9 questions the athlete asks themselves, with the cues they use and where each breaks down. Those breakdowns (B1–B10) now drive feature choices.
